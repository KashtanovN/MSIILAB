# MSIILAB

Программы по предмету «Методы и технологии искусственного интеллекта».

## Лабораторные работы 1 и 2

Тема: «Факторы стабильной работы персонального компьютера».

Программа позволяет редактировать нечёткую когнитивную карту, назначать веса связей, строить матрицу, анализировать циклы и структурную устойчивость, проводить импульсное моделирование. Подготовлены шесть сценариев: три положительные и три негативные ситуации.

### Запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте `index.html` в браузере. Установка и интернет не нужны.

После изменения карты нажмите «Обновить анализ по текущей карте». В разделе «Импульсное моделирование» можно менять начальные значения, импульсы и число шагов.

### Файлы

- `index.html` — готовая программа со всеми необходимыми стилями и кодом.
- `src/` — исходные модули расчётов, интерфейса анализа и сохранения проекта; они также включены в `index.html`.
- [Отчёт по лабораторным работам 1 и 2](reports/Отчет_Каштанов_ПК_ЛР1_ЛР2.docx).

В текущей версии выполнены структурный анализ и импульсные эксперименты. Веса связей являются экспертными оценками; результаты моделирования показывают относительные изменения факторов.
